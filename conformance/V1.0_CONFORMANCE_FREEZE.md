`INIT` → `DISCOVERY` → `REQUIREMENTS` → `SOLUTION` → `APPROVAL` → `PLAN` → `IMPLEMENT` → `TEST` → `VERIFY` → `REVIEW` → `PR_READY`

- `DISCOVERY` $\to$ `REQUIREMENTS`
- `REQUIREMENTS` $\to$ `SOLUTION`
- `SOLUTION` $\to$ `APPROVAL`

- `PLAN` $\to$ `APPROVAL` (Plan Review) | `APPROVAL` $\to$ `IMPLEMENT` (Plan Approved)
- `IMPLEMENT` $\to$ `TEST`

- `REVIEW` $\to$ `PR_READY` (Review Passed) | `REVIEW` $\to$ `IMPLEMENT` (Review Blockers)
- *Express Lane Transitions*: `INIT` $\to$ `PLAN` $\to$ `IMPLEMENT` $\to$ `VERIFY` $\to$ `PR_READY`
