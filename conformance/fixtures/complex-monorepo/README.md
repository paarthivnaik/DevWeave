# Enterprise Travel & Booking Monorepo

Polyglot multi-service architecture for DevWeave complex monorepo conformance validation.

## Topology
- `services/bookings`: Node/TypeScript booking management service
- `services/payments`: Python payment gateway integration
- `services/notifications`: Java email/SMS notification dispatcher
- `frontend`: React/TypeScript client application
- `shared`: Common event schemas and configurations
- `database`: PostgreSQL migration scripts
- `tests/e2e`: End-to-end integration test suites
