# DevWeave Antigravity Reference Adapter (`devweave-antigravity`)

Google Antigravity host adapter and native extensions for DevWeave V1.0.

## Vision
**Less Tokens. More Work. Lower Bill.**

## Overview
`devweave-antigravity` maps the generic, declarative DevWeave AI-DLC specifications into native Google Antigravity constructs:
- Antigravity Skills (`.gemini/skills/*` or host skill formats)
- Antigravity Custom Agents & Subagents
- Antigravity Workflow & Profile mappings
- MCP (Model Context Protocol) configurations & tools

## Architecture
This repository implements the DevWeave Host Contract for Google Antigravity while maintaining 100% adherence to `devweave-spec`.
