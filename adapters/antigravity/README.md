# DevWeave Antigravity Reference Adapter (`adapters/antigravity/`)

Google Antigravity host adapter and native extensions for DevWeave V1.0.

## Vision
**Less Tokens. More Work. Lower Bill.**

## Overview
The Antigravity adapter maps the generic, declarative DevWeave AI-DLC specifications into native Google Antigravity constructs:
- Antigravity Skills (`skills/*`)
- Antigravity Custom Agents & Subagents (`agents/*`)
- Antigravity Workflow & Profile mappings (`workflows/*`)
- MCP (Model Context Protocol) configurations & tools

## Architecture
This adapter implements the DevWeave Host Contract for Google Antigravity while maintaining 100% adherence to `spec/`.
