# DevWeave Discovery Skill (Antigravity)

## Instructions
1. Check `.devweave/repository/` for existing repository intelligence (`technologies.md`, `frameworks.md`, `practices.md`).
2. If intelligence is missing or outdated, perform 5-layer progressive discovery on manifests and configuration files.
3. Query `.devweave/knowledge/` for matching domain rules, repository conventions, and applicable framework best practices.
4. Output discovery summary into work item directory (`discovery.md`).
