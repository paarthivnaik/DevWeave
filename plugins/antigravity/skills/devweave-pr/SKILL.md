# DevWeave PR Skill (`devweave-pr`)

## Execution Invariants
1. **Hard Governance Gate**: External pull request creation strictly requires explicit human sign-off.
2. **Intelligent Review Orchestration**: PR creation requires an approved `review.md` generated by Dual-Model Collective Review (Architect + DBA + Security).
   - If `review.md` is **already available** and `CONSENSUS_APPROVED`, DevWeave uses the verified artifact directly.
   - If `review.md` is **missing or stale**, DevWeave **automatically runs the Phase 6 Dual-Model Review inline** before proceeding.
   - If the review identifies **P0/P1 blocking findings**, DevWeave halts and presents remediation guidance.
3. **Automated Provider PR Creation**: Upon human sign-off at the approval gate, DevWeave automatically pushes the active branch to upstream remote (`git push -u origin <branch>`) and creates the PR via the provider CLI (`gh pr create` for GitHub, `az repos pr create` for Azure DevOps) or outputs the direct web URL.
4. **Deterministic Verification**: Zero tolerance for failing tests or unverified acceptance criteria (`verification.md`).
5. **Audit Invariance**: Record final PR creation, live PR URL, and durable graph promotion in `.devweave/work-items/<ID>/audit.md`.

## Step-by-Step Instructions
1. **Verify Review & Test Status (with Inline Review Orchestration)**:
   - Check `.devweave/work-items/<ID>/test-results.json` for 100% passing tests.
   - Check if `.devweave/work-items/<ID>/review.md` exists and is `CONSENSUS_APPROVED`.
   - **If `review.md` is missing or outdated**:
     - Execute the Dual-Model Collective Review inline (Principal Software Architect + Senior DBA & Security Specialist).
     - Save `.devweave/work-items/<ID>/review.md`.
     - If review produces blocking findings (`CHANGES_REQUESTED`), output the findings, suggest fixes via `devweave-implement <ID>`, and halt.
2. **Durable Knowledge & Graph Delta Promotion**:
   - Apply `.devweave/work-items/<ID>/graph-delta.json` into `.devweave/graph/knowledge-graph.json` to atomically sync the master architecture graph.
   - Prompt the developer to promote any reusable domain conventions, architectural decisions, or schema patterns discovered during the work item to `.devweave/domains/` and `.devweave/knowledge/conventions.md`.
3. **Assemble PR Description**: Write comprehensive PR package to `.devweave/work-items/<ID>/pr-description.md` including:
   - Work Item Summary & Acceptance Criteria fulfillment.
   - Dual-Model Review Summary (Principal Architect + Senior DBA verdicts from `review.md`).
   - Knowledge Graph Delta Summary (Nodes & Edges added/mutated).
   - Downstream Impact & Resilience assessment.
   - Exact file diff summary and test evidence.
4. **Hard Human Approval Gate**:
   ```text
   PR PACKAGE READY
   Work Item: <ID>
   Verification: PASS | Tests: 100% PASS | Dual-Model Review: CONSENSUS_APPROVED
   Architect Review: APPROVED | DBA Review: APPROVED | Security: PASS
   Artifact: .devweave/work-items/<ID>/pr-description.md
   Audit Log: .devweave/work-items/<ID>/audit.md
   
   Authorize pull request creation? [Create PR] [Request Changes] [Stop]
   ```
5. **Execute Automated PR Creation (Upon Approval)**:
   - Push branch upstream:
     ```bash
     git push -u origin <branch_name>
     ```
   - Invoke Provider CLI:
     - **GitHub**:
       ```bash
       gh pr create --title "<ID>: <Title>" --body-file ".devweave/work-items/<ID>/pr-description.md" --base <base_branch> --head <branch_name>
       ```
     - **Azure DevOps**:
       ```bash
       az repos pr create --title "<ID>: <Title>" --description "$(Get-Content .devweave/work-items/<ID>/pr-description.md -Raw)" --target-branch <base_branch> --source-branch <branch_name>
       ```
     - **Custom/Manual**: Output branch pushed confirmation and direct PR link.
   - Display created PR URL to the developer.
6. **Update State & Audit**:
   - Record `PR_COMPLETED` and PR URL in `.devweave/work-items/<ID>/state.md` (and `state.json`).
   - Append final PR completion, provider PR URL, and promotion audit log to `.devweave/work-items/<ID>/audit.md`.
7. **Terminate Execution**: Stop and report completion summary.
