# DevWeave PR Skill (`devweave-pr`)

## Execution Invariants
1. **Hard Governance Gate**: External pull request creation strictly requires explicit human sign-off.
2. **Review Prerequisite**: PR creation requires an approved `review.md` generated by `devweave-pr-review` (Dual-Model Collective Review: Architect + DBA + Security).
   - If `review.md` is **already available** and `CONSENSUS_APPROVED`, DevWeave ignores re-review and uses the verified artifact directly.
   - If `review.md` is **not available** or has blocking findings, DevWeave halts and instructs the developer to run `devweave-pr-review <ID>`.
3. **Deterministic Verification**: Zero tolerance for failing tests or unverified acceptance criteria (`verification.md`).

## Step-by-Step Instructions
1. **Verify Review & Test Status**:
   - Check `.devweave/work-items/<ID>/test-results.json` for 100% passing tests.
   - Check `.devweave/work-items/<ID>/review.md` for `CONSENSUS_APPROVED` verdict.
   - If `review.md` is missing, output:
     ```text
     PR PREREQUISITE MISSING: Code Review Not Found
     Please run Phase 6 Review first: devweave-pr-review <ID>
     ```
     and halt.
2. **Durable Knowledge & Graph Delta Promotion**:
   - Apply `.devweave/work-items/<ID>/graph-delta.json` into `.devweave/graph/knowledge-graph.json` to atomically sync the master architecture graph.
   - Prompt the developer to promote any reusable domain conventions, architectural decisions, or schema patterns discovered during the work item to `.devweave/domains/` and `.devweave/knowledge/conventions.md`.
3. **Assemble PR Description**: Write comprehensive PR package to `.devweave/work-items/<ID>/pr-description.md` including:
   - Work Item Summary & Acceptance Criteria fulfillment.
   - Dual-Model Review Summary (Principal Architect + Senior DBA verdicts from `review.md`).
   - Knowledge Graph Delta Summary (Nodes & Edges added/mutated).
   - Downstream Impact & Resilience assessment.
   - Exact file diff summary and test evidence.
4. **Hard Human Approval Gate**:
   ```text
   PR PACKAGE READY
   Work Item: <ID>
   Verification: PASS | Tests: 100% PASS | Dual-Model Review: CONSENSUS_APPROVED
   Architect Review: APPROVED | DBA Review: APPROVED | Security: PASS
   Artifact: .devweave/work-items/<ID>/pr-description.md
   
   Authorize pull request creation? [Create PR] [Request Changes] [Stop]
   ```
5. **Update State**: Record `PR_COMPLETED` in `.devweave/work-items/<ID>/state.md`.
6. **Terminate Execution**: Stop and wait for user instruction.
