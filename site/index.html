🧠 Graph-Based Durable Memory Engine

Eliminate hallucination and token waste with 1-hop neighborhood queries.

How DevWeave Remembers Your Architecture:

Unstructured AI models rescan your entire repository on every prompt, burning tens of thousands of tokens. DevWeave maintains a declarative JSON Knowledge Graph under .devweave/graph/knowledge-graph.json.

  • Node Indexing: Services, Components, Endpoints, Database Tables, External APIs.
  • 1-Hop Scoping: Injects only the exact dependencies affected by a work item.
  • Graph Deltas: PR creation automatically generates graph-delta.json and merges durable architectural knowledge.
// .devweave/graph/knowledge-graph.json
{
  "version": "1.0.0",
  "nodes": [
    { "id": "svc-orders", "type": "service", "name": "OrderService" },
    { "id": "tbl-orders", "type": "db_table", "name": "orders_v2" }
  ],
  "edges": [
    { "source": "svc-orders", "target": "tbl-orders", "relation": "MUTATES" }
  ]
}

⚡ 1-Click Quick Start & Installation

Select your AI coding host to view instant installation and verification commands.

Google Antigravity CLI (21 Validated Skills)

Install DevWeave natively as an Antigravity plugin directly from GitHub:

# Windows (PowerShell):
git clone --depth 1 -b v1.0.0 https://github.com/paarthivnaik/DevWeave.git $env:TEMP\devweave; agy plugin install $env:TEMP\devweave\plugins\antigravity; Remove-Item -Recurse -Force $env:TEMP\devweave

# macOS / Linux (Bash):
git clone --depth 1 -b v1.0.0 https://github.com/paarthivnaik/DevWeave.git /tmp/devweave && agy plugin install /tmp/devweave/plugins/antigravity && rm -rf /tmp/devweave

# Verify:
agy plugin list
# Output: devweave (plugins/antigravity) - Status: active, Skills: 21 available
