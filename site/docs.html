🌟 1. Product Overview (Simple English Guide)

DevWeave is an open-source software engineering lifecycle framework designed to bring discipline, predictability, and drastic token savings to autonomous AI coding agents.

Core Philosophy: "Less Tokens. More Work. Lower Bill."
DevWeave eliminates the chaos of unstructured AI chat by enforcing deterministic phase boundaries, 1-hop blast-radius scoping, and durable JSON knowledge graphs.

Traditional AI coding assistants scan the whole repository on every prompt, burning 50,000 to 100,000 tokens per interaction. DevWeave replaces full-repo flooding with a declarative knowledge graph, dropping token usage by up to 93.4%.

🧠 2. Graph-Based Durable Memory Engine

The foundation of DevWeave is its declarative JSON Knowledge Graph, stored natively in your project repository under .devweave/graph/knowledge-graph.json.

Why Knowledge Graphs Beat Vector Embeddings:

  • Deterministic Relationships: Tracks exact mutations (e.g., OrderService -> MUTATES -> orders_table).
  • 1-Hop Scoping: When working on a task, DevWeave queries only the immediate 1-hop neighbors of affected components.
  • Zero Hallucination: File touches are bound strictly to graph entities verified during Phase 0 (devweave-init).
  • Graph Deltas: PR creation automatically generates graph-delta.json, promoting durable domain knowledge on merge.
// Formal Schema: spec/schemas/graph.json
{
  "version": "1.0.0",
  "nodes": [
    { "id": "node-auth", "type": "service", "name": "AuthenticationService" },
    { "id": "node-db", "type": "database", "name": "users_table" }
  ],
  "edges": [
    { "source": "node-auth", "target": "node-db", "relation": "READS_WRITES" }
  ]
}

🔄 3. The Canonical 7-Phase AI-DLC Lifecycle

DevWeave organizes engineering work into 7 deterministic phases:

  1. Phase 0: Init (devweave-init): Autonomous 5-layer detection across language, framework, dependencies, build, and test + initializes the Knowledge Graph.
  2. Phase 1: Context (devweave-context <ID>): Ingests work items from Jira/ADO/GitHub/Linear with PII sanitization and 1-hop blast radius scoping.
  3. Phase 2: Analyze (devweave-analyze <ID>): Deep code investigation, schema contracts, and root-cause analysis.
  4. Phase 3: Plan (devweave-plan <ID>): Decomposes solution into atomic tasks with verification anchors and automated test commands.
  5. Phase 4: Branch (devweave-branch <ID>): [HARD GATE] Enforces isolated Git branch creation before source mutations.
  6. Phase 5: Implement (devweave-implement <ID>): Surgical edits strictly bounded to approved plan. Zero hallucinated file touches.
  7. Phase 6: Review (devweave-pr-review <ID>): [HARD GATE] Dual-model consensus review (Principal Architect + Senior DBA).
  8. Phase 7: PR (devweave-pr <ID>): [HARD GATE] Compiles PR package, merges Graph Deltas into durable memory, and awaits human approval.

🛡️ 4. Four Non-Bypassable Governance Gates

Zero Unchecked Hallucination: DevWeave strictly forbids autonomous chaining through phase gates without explicit validation.
  • Gate 1: PII / Privacy Gate: Scans and scrubs raw credentials, passwords, and sensitive customer data before LLM ingestion.
  • Gate 2: Branch Hard Gate: Prevents accidental direct commits to main or master.
  • Gate 3: Test Verification Gate: Requires 100% deterministic test execution evidence before moving to review.
  • Gate 4: Human Review Gate: Requires explicit engineer sign-off on dual-model findings before pull request creation.

👥 5. Dual-Model Collective Code Review

During Phase 6 (devweave-pr-review), DevWeave evaluates code changes through two specialized, independent lenses:

  • Principal Software Architect Lens: Evaluates interface contracts, downstream service impacts, side effects, and cascading failures.
  • Senior Database Administrator (DBA) Lens: Scans SQL statements, table lock hazards, missing indexes, N+1 query hazards, and reversible migration scripts.

⚡ 6. Universal 1-Click Installation

Install DevWeave natively across all 6 supported AI coding hosts with zero runtime background daemons:

🔵 Google Antigravity

# Windows PowerShell
git clone --depth 1 -b v1.0.0 https://github.com/paarthivnaik/DevWeave.git $env:TEMP\devweave; agy plugin install $env:TEMP\devweave\plugins\antigravity; Remove-Item -Recurse -Force $env:TEMP\devweave

# macOS / Linux Bash
git clone --depth 1 -b v1.0.0 https://github.com/paarthivnaik/DevWeave.git /tmp/devweave && agy plugin install /tmp/devweave/plugins/antigravity && rm -rf /tmp/devweave

Autonomous In-Place Daily Auto-Updater

DevWeave includes an autonomous in-place updater (scripts/devweave-update.ps1 & scripts/devweave-update.sh) featuring a 24-hour TTL check.

  • 0 LLM Tokens: Updates natively via Git shallow fetches in ~1.5s.
  • 0ms Latency on Cache Hit: Runs only once per day; subsequent prompts run with zero delay.
  • Dual-Scope Sync: Updates both user-global host directories and local project repositories (.agents/plugins/devweave/ and .github/prompts/).
  • On-Demand Upgrade: Type /devweave-update anytime to force an instant sync to the newest release.

🤖 7. Automated Release Process with GitHub Actions

DevWeave features a complete CI/CD release workflow in .github/workflows/release.yml. Whenever a version tag (e.g. v1.1.0) is pushed:

  1. Automated Testing: Runs JSON Schema validation and the complete 6-suite conformance test runner.
  2. Packaging: Builds 6 standalone host plugin ZIP files + 1 complete multi-host bundle in dist/.
  3. GitHub Release Publication: Generates changelog notes and attaches downloadable archives.
  4. Documentation Portal Deployment: Automatically deploys site/ to GitHub Pages.
