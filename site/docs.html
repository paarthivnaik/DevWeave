DevWeave V1.0 Overview

DevWeave is the universal AI-DLC (AI-Driven Development Lifecycle) framework. It eliminates the chaos, token waste, and hallucination loops of unstructured AI coding assistants through strict phase boundary enforcement, surgical blast-radius scoping, and compounding domain knowledge.

Supported Host Platforms

DevWeave is structured with 100% structural parity across 6 host environments:

  • Google Antigravity: plugins/antigravity/ (20 validated skills)
  • Anthropic Claude Code: plugins/claude/ (20 slash commands)
  • GitHub Copilot: plugins/copilot/ (20 prompt files & extension)
  • Google Gemini CLI: plugins/gemini/ (20 command definitions)
  • OpenAI Codex / ChatGPT CLI: plugins/codex/ (20 commands)
  • Cognition Devin: plugins/devin/ (20 deterministic playbook actions)

Human-in-the-Loop Governance Checkpoints

DevWeave enforces 4 non-bypassable governance checkpoints:

  1. Context Approval Gate: Requires engineer sign-off on work item scope before analysis begins.
  2. Branch Hard Gate: Prevents file touch until an isolated Git branch is created.
  3. Test & Verify Gate: Deterministic verification requiring clean test runs before review.
  4. PR Review Consensus Gate: Dual-model code review (Architect + Senior DBA) requiring human consensus sign-off before pull request creation.

Dual-Model Collective Code Review

Phase 6 (devweave-pr-review) executes an automated, multi-perspective code audit:

  • Principal Software Architect Lens: Evaluates interface contracts, downstream service impacts, side effects, and cascading failures.
  • Senior Database Administrator (DBA) Lens: Audits SQL statements, table lock hazards, index coverage, and reversible migration scripts.

Central Compounding Knowledge Base

Rather than re-analyzing repositories from scratch on every turn, DevWeave stores domain knowledge under .devweave/domains/ and .devweave/products/. This yields:

  • 93.3% Token Savings on subsequent tasks in the same domain.
  • 0 Rediscovery Latency.
  • Continuous knowledge promotion as PRs are merged.
